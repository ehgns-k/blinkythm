Every window now uses the pixel style. The old Windows dialogs are gone.

- Settings, the first-run setup and the reminder popup are drawn like the game. The main window hides to the tray instead of closing.
- New timing calibration: a steady 60 BPM metronome (slower than the old 90 BPM) that you blink along to for as long as you like. The offset is a running median that you accept once it settles.
- The reminder is a small borderless window in the corner. It does not take keyboard focus and only reacts to the mouse.
- Tray menu: Open, Play now, Settings, Monitor blinking, Exit.
- Settings and calibration from earlier versions carry over.

Unzip `Blinkythm-v1.2.0-win64.zip` and run `Blinkythm.exe`. Requires Windows 10 or later (64-bit), a webcam and speakers or headphones. The exe is not signed yet, so SmartScreen may warn; choose "More info" and "Run anyway".

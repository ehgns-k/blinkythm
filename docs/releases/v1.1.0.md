New game window built with pygame-ce. It no longer looks tiny on high-DPI monitors.

- The game draws on a 384x216 pixel screen scaled by a whole number to fit: 4x at 1080p, 8x at 4K. The window is resizable and F11 toggles fullscreen.
- New flow: home (your eyes today, stamp card), game select, play, result stamp, then a 20-second look-far-away break.
- Blink twice to press the main button on home, game select and results.
- Gentler stamps: Superb, Nice, Good, Rested.
- The whole app is now in English. Text in the game uses the Galmuri bitmap font (SIL OFL 1.1).
- Settings and calibration from 1.0.1 carry over.

Unzip `Blinkythm-v1.1.0-win64.zip` and run `Blinkythm.exe`. Requires Windows 10 or later (64-bit), a webcam and speakers or headphones. The exe is unsigned, so SmartScreen may warn; choose "More info" and "Run anyway".
